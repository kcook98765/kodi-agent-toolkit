# Community conduct

Treat contributors and users with respect. Discuss the technical problem, give actionable feedback, and welcome differing experience levels. Harassment, threats, discriminatory abuse, unwanted personal contact, and disclosure of another person's private information are unacceptable.

These expectations apply in repository issues, pull requests, and other project spaces. Maintainers may edit or remove disruptive content, close discussions, or restrict participation, applying the same expectations to themselves. Concerns about conduct should be shared with the maintainer through an existing private channel; do not repost personal information in a public issue. Security vulnerabilities use the private process in SECURITY.md.

This is an original project policy, distributed under the repository's MIT license.
