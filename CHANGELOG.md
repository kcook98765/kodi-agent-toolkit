# Changelog

## Unreleased

Added portable OpenCode 1.x presets for development, runtime testing and five
read-only inspection roles, plus a disabled private MCP connection template and
Linux/WSL/PowerShell installation guide. Presets inherit the receiving model and
use existing toolkit skills without copying workstation paths, credentials,
target IDs or production authorizations. Configuration loading was checked with
OpenCode 1.19.0; this does not qualify new model-driven or runtime behavior.

Refresh portable development/debugging/MCP guidance against the 2026-10-29 Kodi Lab contract: durable preflight, reviewed source staging, exact-generation and repeated-deployment evidence, qualified activation limits and safe recovery. Add a short everyday workflow and distinguish current discovery from historical beta evaluations. CLI schemas, dependency pins, fixture adapters and release version are unchanged. No new runtime or cross-version acceptance is claimed.

## 0.1.0-beta.1

First reviewed public source snapshot. Added a complete Linux/Windows standalone quick start, portable skill installation guidance, community templates, verified GitHub Sponsors metadata, minimal standalone CI, release notes, and a publication plan. Removed workstation-specific evaluation provider aliases/observer wiring and implicit discovery of workstation token files; optional exact-value redaction now reads only explicitly named private files. Added Git line-ending rules to preserve source/evaluation hashes on native Windows clones. Retained the Phase 6 deterministic functionality, fixtures, locked dependencies, license, and sanitized evaluation evidence.

Model review/repair and Kodi Lab runtime integrations remain experimental. Runtime deployment and reproduction are unqualified. See docs/phase6-results.md and docs/phase7-results.md.
