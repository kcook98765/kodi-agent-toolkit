# Changelog

First reviewed public source snapshot. Added a complete Linux/Windows standalone quick start, portable skill installation guidance, community templates, verified GitHub Sponsors metadata, minimal standalone CI, release notes, and a publication plan. Added Git line-ending rules to preserve source/evaluation hashes on native Windows clones. Retained the Phase 6 deterministic functionality, fixtures, locked dependencies, license, and sanitized evaluation evidence.

Model review/repair and Kodi Lab runtime integrations remain experimental. Runtime deployment and reproduction are unqualified. See docs/phase6-results.md and docs/phase7-results.md.
